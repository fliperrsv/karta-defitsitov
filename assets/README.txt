ПАПКА АССЕТОВ
=============

Сюда кладите реальные фото из исходников Марии.

Файл photo.jpg подставится на страницу автоматически:
если его нет — вместо него показывается нарисованный заполнитель
(тарелка с лососем), страница не ломается.

Для будущих страниц отчёта добавляйте файлы с понятными именами:
photo-2.jpg, diagram-iron.svg и т.д. — и указывайте путь в js/data.js.
